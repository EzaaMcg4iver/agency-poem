# agency-poem

[![make.fun · agency-poem-01](https://make.fun/badge/agency-poem-01.svg)](https://make.fun/bounty/agency-poem-01?utm_source=github&utm_medium=readme&utm_campaign=agency-poem-01)

One short poem about agency — the power to choose and to act, and the agency that passes between a person and the agent they built, when the doing is handed over and the deciding stays.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), the same bytes on every run, so two runs write identical bytes. Python 3.13, standard library only.
